短信验证码转发设置

电脑端

令牌必须与 Windows 端 config.ini 中的 token 完全一致。

电脑端（第二台，可选）

填写后短信会同时发送到两台电脑；留空则不发送到第二台。令牌必须与第二台电脑 config.ini 中的 token 完全一致。

公网 ntfy（可选）

服务器必须使用 HTTPS。只使用局域网时，主题和令牌都留空。公共主题名不是可靠的访问控制，应优先使用带身份认证的私有服务。

识别设置

读取间隔用于检查新短信，与界面刷新率无关。

配置可能包含访问令牌。具有相应文件访问权限的程序可能读取配置，请勿公开配置文件或含敏感信息的截图。
