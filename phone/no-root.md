# 免 root 手机端

免 root 方案通过短信转发应用的 Webhook 功能，把新短信发送到 Windows 端。无需解锁 Bootloader、获取 root 或安装 codepass Android 模块，适合大多数用户。

## 准备工作

1. 手机和电脑连接同一个 Wi-Fi，或已通过 VPN/EasyTier 互通；
2. Windows 端已经运行 codepass；
3. Windows 设置页已确认电脑 IPv4 地址、端口和访问令牌；
4. 已安装支持 Webhook 的短信转发应用，例如 [SmsForwarder](https://github.com/pppscn/SmsForwarder)。

## 配置步骤

### 1. 授予权限

首次打开短信转发应用时，按系统提示授予：

- 短信权限；
- 通知权限；
- 网络权限。

如果应用提供电池优化设置，请选择“不限制”，并允许自启动和后台活动。

### 2. 创建 Webhook 通道

在应用的发送通道中新增 Webhook：

```text
请求方式：POST
地址：http://电脑IPv4地址:8787/sms
正文：短信正文变量
```

常见短信正文变量为：

```text
{{SMS}}
```

不同应用的变量名称可能不同，请以应用内的变量列表为准。

Windows 端设置访问令牌时，可以将令牌放入 URL：

```text
http://192.168.1.100:8787/sms?token=你的令牌
```

如果应用支持自定义请求头，也可以使用：

```text
X-Token: 你的令牌
```

令牌必须与 Windows 端完全一致。

### 3. 创建转发规则

新增一条短信转发规则：

1. 选择需要转发的短信来源，或设置短信内容条件；
2. 发送通道选择刚才创建的 Webhook；
3. 保存规则；
4. 使用应用提供的测试功能发送一条测试内容。

电脑端记录页出现测试验证码后，说明基本连接正常。

## 外出使用

局域网地址不能直接跨互联网访问。手机离开家庭网络后，可配置 ntfy 作为公网中转，具体方法见 [`ntfy.md`](ntfy.md)。

## 后台运行设置

如果锁屏后停止转发，请在系统设置中检查：

- 电池使用是否设置为“不限制”；
- 是否允许自启动；
- 是否允许后台活动和后台联网；
- 是否可以在最近任务中锁定应用。

不同品牌手机的菜单名称可能不同，可搜索“电池优化”“自启动”“后台运行”。

## 常见问题

### 电脑无法连接

确认手机和电脑位于同一网络，电脑地址使用当前 IPv4，端口默认为 `8787`，并检查 Windows 防火墙是否允许专用网络入站连接。

### 电脑收到短信但没有识别验证码

确认 Webhook 正文确实包含短信内容，并检查 Windows 端的验证码长度范围。默认识别 4～8 位连续数字。

### 短信正文被隐藏

部分系统的验证码保护功能会隐藏短信正文。可以在系统设置中调整相关保护，或改用 root 方案。

## 安全提示

短信和验证码属于敏感信息。请使用随机访问令牌，不要把包含令牌的 URL、截图或导出配置发布到公开位置。使用公网转发时，建议采用 HTTPS 的 ntfy 服务。
