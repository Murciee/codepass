# Gmail 应用专用密码设置

codepass 的 Gmail 邮箱接收使用 IMAP 和 Gmail 应用专用密码，不需要注册 Google Cloud 项目、OAuth 客户端或配置浏览器回调。

## Gmail 设置

1. 开启 [Google 两步验证](https://myaccount.google.com/security)。
2. 打开 [应用专用密码](https://myaccount.google.com/apppasswords)。
3. 为 codepass 创建一个应用专用密码。Google 通常显示 16 位密码，输入时去掉空格即可。

如果账号属于 Google Workspace、启用了高级保护，或组织管理员禁止应用专用密码，这个入口可能不可用，需要联系管理员或使用组织允许的 IMAP 授权方式。

## codepass 设置

1. 打开“邮箱设置”，选择 Gmail。
2. 填写完整 Gmail 地址。
3. 在“授权码 / 应用专用密码”中填写刚生成的密码，不能填写 Gmail 网页登录密码。
4. 点击“测试邮箱连接”，确认认证和只读打开收件箱成功。
5. 开启“接收邮箱里的验证码邮件”。

程序只执行 IMAP 的 `EXAMINE`、`SEARCH` 和 `BODY.PEEK`，不会把邮件标记为已读。默认只保存发件人和验证码；如果需要保留正文，可在邮箱设置中单独开启正文保存。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 应用专用密码入口不存在 | 确认两步验证已开启；Workspace 或高级保护账号可能被管理员限制 |
| 认证失败 | 确认填写的是应用专用密码，不是网页登录密码；确认网页版邮箱已允许 IMAP |
| 测试连接成功但没有验证码 | 查看邮件处理原因，检查主题关键词和发件人规则；此前已跳过的邮件可点击“重新检查近 30 分钟”补收录 |
| 更换 Windows 用户后密码失效 | 邮箱授权码使用 Windows 当前用户 DPAPI 加密存储，请重新填写 |

QQ、163、126 和其他自定义 IMAP 服务仍使用各服务商生成的 IMAP 授权码或应用专用密码。
