# 可靠性、交互与响应改进验收（2026-10-12）

## 本次落地

### 接收与投递

- SMS 稳定消息身份和双通道幂等；旧文本客户端按正文指纹做两分钟去重。
- ntfy 最近十分钟缓存补收、重叠边界秒、成功/明确忽略后确认、事件凭据持久化、损坏内容单条隔离和异常时间保护。
- root `phone/forward.sh` 按 ID 扫描新增短信，按 ID 单独读取正文；持久待发队列、独立目标确认、三通道并发、失败重试、十分钟过期、最多 1000 条。状态校验或任何队列写入失败保留原状态。
- 分类邮箱连接复用，目录列表每五分钟刷新；成功轮询重置连续失败退避。
- 静默启动延迟构造完整主窗口；独立消息窗口作为剪贴板 owner。自动复制先调度，历史刷新合并；暂停自动复制也终止待重试的自动任务。

### 界面与交互

- 配置按区校验、保留无效草稿；普通设置后台串行保存，邮箱连接使用显式保存。
- 最新运行配置上合并分区，保留后台邮件水位；磁盘与启动项独立补偿；异步结果按原子分区版本隔离，关闭前排空并记录失败。
- 网络/邮箱测试可取消，使用结构化成功/失败状态和草稿版本，锁定/关闭后不显示迟到结果。ntfy 测试与正式订阅使用相同系统代理策略。
- 最新验证码卡、接收摘要、首次接入入口、带网卡名称的地址菜单、Webhook 说明、临时暂停自动复制。
- 历史行使用可由 Tab/Enter 激活的复制和原文按钮；Ctrl+F 搜索，搜索合并刷新，ToolTip 延迟构造，保留滚动位置及返回顶部操作。
- 邮箱状态卡收紧、高级项折叠、服务商教程按需显示、输入框适应宽度；记录清理折叠并提示 100 条上限和有效期区别。
- 单窗口设置/修改/关闭密码锁；锁屏隐藏并禁用业务树、焦点循环，复制操作检查锁态。
- 640×460 低高度布局保留记录列表；系统高对比度使用系统颜色与原生控件模板，减少动画时关键帧即时完成。
