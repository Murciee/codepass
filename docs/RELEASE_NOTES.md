# 发布说明

## codepass v1.0.4

新增邮箱验证码接收，并改善记录查找、设置分区和托盘使用。手机模块保持 v1.0.3，无需重装。

### 更新内容

- **邮箱验证码**：支持 QQ、163、126、Gmail、Outlook 与自定义 IMAP，可按主题和发件人筛选。
- **记录管理**：新增搜索和全部 / 短信 / 邮件筛选；自动清理默认 10 分钟，`0` 停用，不删除邮箱邮件。
- **设置界面**：常规/安全设置调整为短信、邮箱、隐私分区；邮箱状态置顶，窄窗口标签上移、按钮换行。
- **通知隐私**：短信与邮件独立选择通知内容。
- **静默启动**：开机只驻留托盘，双击打开主窗口。
- **脱敏诊断**：关于页先预览，再保存分享。

主要功能界面见 [README 四宫格截图](https://github.com/Murciee/codepass#功能截图)。

### 下载与升级

| 附件 | 版本与用途 |
| --- | --- |
| `codepass-windows.zip` | v1.0.4，解压后运行 `codepass.exe` |
| `codepass-sms-magisk.zip` | 手机端 v1.0.3，继续兼容本次更新 |
| `codepass-lsposed-release.apk` | 手机端已签名 v1.0.3，继续兼容本次更新 |
| `SHA256SUMS.txt` | 本次附件校验值 |

从托盘退出后覆盖 `codepass.exe`，保留配置与记录。需要长期保留记录时，将自动清理设为 `0`。

Windows 包未做代码签名，可能显示未知发布者；不要为此关闭系统安全功能。本项目为个人开源工具，不承诺所有设备兼容。
