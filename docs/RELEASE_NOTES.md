# 发布说明

## codepass v1.1.0

优化主窗口隐藏到托盘后的资源释放，降低长期运行时的内存驻留。

### 更新内容

- **隐藏窗口资源优化**：关闭主窗口到托盘时释放历史列表动态控件、历史原文/诊断窗口和页面级计时器；保留设置草稿、窗口句柄和后台接收服务，重新打开记录页时按需重建历史列表。
- **托盘操作优化**：隐藏状态下清空记录不会重新创建窗口 Toast 或历史控件；从托盘打开设置页、关于页时不会无谓重建历史列表，进入记录页时再刷新。
- **稳定性验证**：新增隐藏/恢复生命周期回归，验证设置草稿、窗口句柄、历史筛选、托盘操作和后台保留清理不受影响。

## codepass v1.0.9

修复开机自启后第一次接收不通、需要关掉程序重开的问题。

### 更新内容

- **启动接收修复**：电脑接收服务在启动时绑定失败（例如登录时虚拟网卡地址还没就绪、或重启瞬间旧实例仍占用端口）后会按退避间隔自动重试，地址或端口一可用就自动恢复监听；此前一次绑定失败会让整个会话收不到短信，只能关闭程序重开。
- **接收服务状态**：短信设置的电脑地址卡片新增接收服务状态与实际监听端点；被降级为只监听本机（手机无法连接）时会明确标出，测试连通性失败时也会说明是本机服务没绑上。

## codepass v1.0.8

短信接收规则增强，减少普通通知被误识别为验证码。

### 更新内容

- **短信接收关键字**：短信设置新增与邮箱关键词一致的标签式管理，可添加、移除、批量编辑和恢复默认关键词；留空时仍可接收全部短信。
- **默认验证码词表**：内置常见中文和英文验证码表达，覆盖登录、支付与邮箱验证等常见场景。
- **误收防护**：日期中的年份不再作为无上下文验证码回退结果，降低政务、账号开通等普通通知被识别为验证码的情况。

## codepass v1.0.6

记录页精简，强调最新验证码，改进模块架构。

### 更新内容

- **记录页精简**：移除手机短信、ntfy、邮箱接收状态区和接入按钮；去掉列表上方重复的"操作"标题，保留每行"操作 ▾"按钮；清理时间设置常驻显示。
- **最新验证码强调**：仅最新记录的验证码使用蓝色，旧记录使用正文黑色；搜索筛选不会将旧项提升为最新项，相同验证码按具体记录引用区分。
- **架构改进**：HTTP、ntfy、消息投递、剪贴板分别由独立模块管理；可见记录与接收凭据账本职责分离，保持单次原子提交与失败回滚。
- **问题修复**：修复较旧消息晚到时可能覆盖更新验证码的问题；修复退出期间接收器可能提前确认未落盘消息的问题。

## codepass v1.0.4

新增邮箱验证码接收，并改善记录查找、设置分区和托盘使用。手机模块保持 v1.0.3，无需重装。

### 更新内容

- **邮箱验证码**：支持 QQ、163、126、Gmail、Outlook 与自定义 IMAP，可按主题和发件人筛选。
- **记录管理**：新增搜索和全部 / 短信 / 邮件筛选；自动清理默认 10 分钟，`0` 停用，不删除邮箱邮件。
- **设置界面**：常规/安全设置调整为短信、邮箱、隐私分区；邮箱状态置顶，窄窗口标签上移、按钮换行。
- **通知隐私**：短信与邮件独立选择通知内容。
- **静默启动**：开机只驻留托盘，双击打开主窗口。
- **脱敏诊断**：关于页先预览，再保存分享。

主要功能界面见 [README 四宫格截图](https://github.com/Murciee/codepass#功能截图)。
