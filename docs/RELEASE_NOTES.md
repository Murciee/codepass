# 发布说明

## codepass v1.0.7

界面优化与自动更新。

### 更新内容

- **界面优化**：密钥框眼睛改为圆润矢量图标（睁眼/闭眼均含睫毛），整体墨迹居中；双向切换后光标停在内容末尾。
- **托盘菜单扩充**：新增「查看记录」「清空记录」「打开设置」「显示主窗口」「检查更新」，鼠标悬停蓝色高亮。
- **自动更新**：检查新版后一键下载、校验、替换并重启；失败时自动恢复旧版本；配置和记录保留。
- **布局调整**：记录页"清空全部记录"按钮移到右下角；设置页卡片顺序优化。

## codepass v1.0.6

记录页精简，强调最新验证码，改进模块架构。

### 更新内容

- **记录页精简**：移除手机短信、ntfy、邮箱接收状态区和接入按钮；去掉列表上方重复的"操作"标题，保留每行"操作 ▾"按钮；清理时间设置常驻显示。
- **最新验证码强调**：仅最新记录的验证码使用蓝色，旧记录使用正文黑色；搜索筛选不会将旧项提升为最新项，相同验证码按具体记录引用区分。
- **架构改进**：HTTP、ntfy、消息投递、剪贴板分别由独立模块管理；可见记录与接收凭据账本职责分离，保持单次原子提交与失败回滚。
- **问题修复**：修复较旧消息晚到时可能覆盖更新验证码的问题；修复退出期间接收器可能提前确认未落盘消息的问题。

## codepass v1.0.4

新增邮箱验证码接收，并改善记录查找、设置分区和托盘使用。手机模块保持 v1.0.3，无需重装。

### 更新内容

- **邮箱验证码**：支持 QQ、163、126、Gmail、Outlook 与自定义 IMAP，可按主题和发件人筛选。
- **记录管理**：新增搜索和全部 / 短信 / 邮件筛选；自动清理默认 10 分钟，`0` 停用，不删除邮箱邮件。
- **设置界面**：常规/安全设置调整为短信、邮箱、隐私分区；邮箱状态置顶，窄窗口标签上移、按钮换行。
- **通知隐私**：短信与邮件独立选择通知内容。
- **静默启动**：开机只驻留托盘，双击打开主窗口。
- **脱敏诊断**：关于页先预览，再保存分享。

主要功能界面见 [README 四宫格截图](https://github.com/Murciee/codepass#功能截图)。
