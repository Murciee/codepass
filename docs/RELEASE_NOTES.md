# 发布说明

## codepass v1.0.4

本次更新 Windows 客户端，重点改善记录查找、邮箱设置和日常使用。手机端仍为 v1.0.3，继续兼容，无需重新安装。

### 与 v1.0.3 相比，界面有哪些不同？

| 使用位置 | v1.0.3 | v1.0.4 |
| --- | --- | --- |
| 左侧导航 | 记录、常规设置、安全设置、关于 | 记录、短信设置、邮箱设置、隐私设置、关于，功能入口更明确 |
| 验证码记录 | 浏览最近记录 | 新增搜索框和全部 / 短信 / 邮件筛选，可按服务名、发件人或验证码寻找记录 |
| 记录保留 | 手动清空 | 底部可设置自动清理，默认 10 分钟，填写 0 停用 |
| 邮箱设置 | 没有独立邮箱页 | 独立页面，顶部显示实时状态，下方分为连接、接收规则和高级设置 |
| 通知隐私 | 统一的通知内容选择 | 短信与邮件分别选择通知内容，集中在隐私设置 |
| 排障入口 | 手工整理信息 | 关于页增加“预览脱敏诊断”，确认内容后再保存分享 |
| 窄窗口 | 标签与输入横排 | 标签移至输入框上方，按钮按宽度换行 |
| 开机启动 | 弹出主界面 | 静默驻留托盘，双击托盘图标再打开；手动启动仍显示窗口 |

记录搜索支持多个词，空格分隔后同时匹配；无结果时显示明确提示，“重置筛选”恢复全部。点击验证码复制，悬停预览原文，双击原文可打开完整内容。

邮箱页可测试连接、重新检查近 30 分钟的验证码邮件，并查看处理结果；邮件正文默认不保存，需要时在高级设置中开启。未保存正文的邮件可按发件人、验证码或时间搜索。

自动清理只清除本程序保存的短信和邮件记录，**不删除邮箱中的邮件**。过期记录在下次启动时也会清理。需要长期保留记录的用户，请在升级后将分钟数改为 **0**。

### 下载与升级

| 附件 | 版本与用途 |
| --- | --- |
| `codepass-windows.zip` | v1.0.4，解压后运行 `codepass.exe` |
| `codepass-sms-magisk.zip` | 手机端 v1.0.3，继续兼容本次更新 |
| `codepass-lsposed-release.apk` | 手机端已签名 v1.0.3，继续兼容本次更新 |
| `SHA256SUMS.txt` | 本次附件校验值 |

Windows 先从托盘退出，再覆盖 `codepass.exe`，保留自己的配置与记录。已有自启动设置会自动更新；关闭窗口仍隐藏到托盘，完全退出请用托盘菜单。

Windows 包未做代码签名，可能显示未知发布者；不要为此关闭系统安全功能。本项目为个人开源工具，不承诺所有设备兼容。

反馈时优先使用“关于 → 预览脱敏诊断”，核对后保存报告；请勿分享真实验证码、短信/邮件正文、令牌或完整配置。
