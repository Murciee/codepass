# 邮箱切换与短信长度上限修复

版本保持 v1.0.3，未发布。

- 邮箱服务切换会保存新服务器、暂停接收并清空旧服务授权码。用户填写新凭据后再开启接收。
- 首次原子保存失败时保留原文件，只恢复内存和界面，不再重复写盘并制造“保存且还原失败”的状态。
- 已有恢复失败标记允许同值重试；再次写盘失败继续保留标记，成功写盘后解除。
- 保存失败提示区分只读/权限、文件占用、Windows 加密失败等类别；不会阻止窗口隐藏、托盘退出或系统关闭。
- 短信设置新增可调长度上限，默认 500 字符，范围 1～10000；超过上限整条忽略，不进入提取、历史、通知或剪贴板。HTTP 和 ntfy 共用限制，邮箱不受影响。
- 中文按字符而非 UTF-8 字节计数，合法代理对（例如 emoji）算一个字符，空格与换行也计入。配置事务与短信接收共用锁，失败回滚期间不会采用临时上限。
