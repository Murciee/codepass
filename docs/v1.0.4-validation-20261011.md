# codepass v1.0.4 验证记录

本次交付更新 Windows 客户端到 v1.0.4，手机端继续使用 v1.0.3 已签名附件。

## 用户可见变化

- 开机启动静默驻留托盘，首次接收前也已准备好复制所需的隐藏窗口句柄；手动启动和托盘双击仍可打开主窗口。
- 记录页默认自动清除超过 10 分钟的短信和邮件本地记录，0 停用；启动、设置修改、新记录和运行中的定时检查都会处理过期记录，不删除邮箱邮件。
- 记录页搜索、通道筛选、邮箱实时状态、短信/邮箱设置分区、隐私选择和脱敏诊断保持可用；5 张新版截图来自本次合成窗口渲染，数据为虚构内容。
