# 安全代码邮件与记录原文交互

版本仍为 v1.0.3，未发布。

## 邮件接收

- 增加“安全代码”“安全码”的明确提取上下文和默认主题关键词。
- 纯文本正文没有明确验证码时，继续检查 HTML 正文，防止纯文本只是提示或参考编号而 HTML 才含安全代码。
- FETCH 头部/正文按请求 UID 关联，兼容 literal 后续行；已移走的邮件跳过，头部不完整的现存邮件重试。
- 修改主题关键词、发件人规则或验证码长度后，自动请求复查近 30 分钟邮件；也可点击“重新检查近 30 分钟”。
- 复查每文件夹最多 200 封候选，再用服务器 INTERNALDATE 严格过滤 30 分钟，保留原水位。邮件身份去重凭据独立于 100 条展示历史，加密保存 35 分钟，最多 4096 条；复查补收录不自动复制，也不覆盖托盘“最新验证码”，该标记在重启后继续有效。
- 复查请求绑定当前服务器、账户和凭据；切换身份或停用会取消旧请求，同账户规则调整保留请求。收件箱与垃圾箱分别唤醒。
- 连接状态下面显示主题未命中、发件人未命中、正文没有合适验证码、头部读取失败等处理结果。

已有配置的自定义关键词会保留。请确认含“安全代码”，然后点击一次“重新检查近 30 分钟”；超过 30 分钟的邮件需要重新触发一封新的验证码邮件。

## 记录原文

- 发件人列居中，原文列保持左对齐。
- 原文悬停显示换行、可滚动预览，双击打开可调整大小的全文窗口；可选择文字，Esc 或关闭按钮退出。
- 原文窗口显示记录里保存的全文，不只显示列表中省略的内容。
- 邮件正文仍默认不保存。开启后保存选中的正文（读取上限 20000 字符）与主题，不再仅保留 1000 字符。读取或字符截断会附加提示；旧记录未保存的正文不能恢复。
- 主窗口锁定时关闭原文窗口；启用自动锁后，最小化原文窗口也触发锁定并关闭原文窗口。

## 验证

最终合成回归共 130 项通过：邮件/原文交互 58 项、既有邮箱切换/保存恢复/短信上限 72 项。包含 Microsoft 安全代码样式的 MIME 编码主题、纯文本/HTML 回退、修改关键词后的补收录、205 封邮件跨重启去重、30 分钟边界、FETCH 续行、原文双击/自动锁、截断提示及最新验证码恢复。

独立只读审查发现的原文窗口自动锁、复查去重、请求账户绑定、垃圾箱唤醒、正文截断提示、复查影响最新验证码（含重启恢复）均已针对性修复并复核关闭。编译与差异格式检查通过，未提交、推送或发布。
